# Advisor UI smoke-check (manual)

> Nota: no ejecutar builds. Solo smoke-check visual.

## Pasos
1. Abrí la app en `apps/simulator-vue` (dev server).
2. En el dashboard, completá parámetros mínimos si hace falta.
3. Hacé click en **"Ejecutar Simulación"**.
4. Verificá que el panel **AdvisorPanel** aparezca debajo del gráfico con recomendaciones (si hay matches).
5. Confirmá que **no** se recalcula mientras tipeás inputs (solo después de ejecutar la simulación).
